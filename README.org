#+TITLE: org-sty.el — Org Style your buffers. Build a Word Processor
#+AUTHOR: Brad

A collection of Emacs minor modes that together aim to emulate a
word-processor interface inside Org mode. Each file is independently
usable; they are wired together through =org-sty='s =:eval= escape hatch.

* Files

** =face-extra.el= — synthetic face-property engine

Provides a generic mechanism for synthetic face attributes — display
effects not expressible as standard Emacs face attributes (line-spacing
ratios, text alignment, etc.). Properties are registered once at load
time with a pass number (1–3) and apply/clear callbacks; the dispatch
is hooked into jit-lock via advice on
=font-lock-fontify-keywords-region=.

Properties are attached to faces globally or buffer-locally:

#+begin_src emacs-lisp
(face-extra-add-relative 'org-quote 'variable-spacing-ratio 1.0)
#+end_src

=face-extra-mode= is ref-counted: use =face-extra-mode-require= /
=face-extra-mode-release= from dependent modes rather than toggling it
directly.

** =body-face.el= — body-face hierarchy

=body-face-mode= installs a semantic body-face layer in a buffer. Content faces (headings, prose, blocks, links, …) receive =(:inherit body)= remaps, decoupling them from emacs' basic =default= face behaviour; metadata faces (drawers, keywords, block delimiters, …) remain anchored to =default=. This way, they can be styled separately from body text, for example, making variable-spacing mode possible and for allowing a buffer to use faces that are smaller than primary content, a significant drawback of the standard emacs approach which =default=. A pass-0 fontifier adds the =body= face on bare paragraph text that Org leaves unfaced. (org is a first-class citizen, it's our design target, but a simple, pluggable backend structure allows using this module for other major modes).

=body= is intentionally neutral (=:inherit default=), but it can be styled completely independently of =default=.

** =org-sty.el= — style dispatcher

Applies a visual "profile" to an Org buffer based on its =#+FILETAGS=.
Define styles per tag in =org-sty-alist=; when a tagged file opens, the
matching style(s) are merged and applied.

*** Recognised plist keys

| Key               | Effect                                                 |
|-------------------+--------------------------------------------------------|
| =:font=           | Font family name, e.g. ="Times New Roman"=             |
| =:font-size=      | Point size, e.g. =12=                                  |
| =:num-level=      | Heading depth for =org-num-mode=; =0= to disable       |
| =:indent=         | =t=/=nil= to enable/disable =org-indent-mode=          |
| =:olivetti-width= | Body width for =olivetti-mode=                         |
| =:faces=          | Alist of =(FACE . ATTRS)= buffer-local face remaps     |
| =:eval=           | A form or list of forms evaluated after all other keys |

=:eval= is the escape hatch for anything not covered above — enabling
the other modes in this collection, calling =org-sty-remap= for runtime
face remaps, etc.

*** Merge semantics

If a buffer has multiple matching tags, their styles are merged in
=org-sty-alist= order (later entries win). =org-sty-default= provides a
baseline applied to every Org buffer before any tag-specific style.

*** =:faces= and =org-sty-remap=

=:faces= accepts an alist of =(FACE . ATTRS)= and installs buffer-local
face remaps tracked in =org-sty--face-remap-cookies=. For runtime logic
use =org-sty-remap= inside =:eval=:

#+begin_src emacs-lisp
(org-sty-remap 'org-quote :slant 'italic :variable-spacing-ratio 1.3)
#+end_src

All remaps (including =:variable-spacing-ratio=, routed through
=face-extra-add-relative=) are cleaned up automatically on style
re-apply or buffer kill.

*** Setup

#+begin_src emacs-lisp
(add-hook 'org-mode-hook #'org-sty-mode)

(setq org-sty-default
      '(:font "Iosevka Aile"
        :eval (...)))           ; baseline for all Org buffers

(setq org-sty-alist
      '(("thesis" . (:font "Times New Roman" :font-size 12
                     :num-level 3 :indent nil :olivetti-width 68
                     :faces ((org-level-1 . (:height 2.4))
                             (org-level-2 . (:height 2.2)))
                     :eval (progn
                             (variable-spacing-mode 1)
                             (horizontal-layout-mode 1)
                             (org-block-appear-mode 1)
                             (org-title-fold-mode 1))))))
#+end_src

** =variable-spacing.el= — proportional line spacing

=variable-spacing-mode= applies proportional line spacing to buffer elements on a per-face basis. Spacing is implemented as pixel-height =line-prefix=/=wrap-prefix= display properties applied lazily via jit-lock. The pixel height is computed from the live rendered font so it tracks =text-scale-mode= correctly.

Depends on =body-face-mode= (enabled automatically).

*** Usage

Spacing ratios are attached to faces via the face-extra API:

#+begin_src emacs-lisp
(face-extra-add-relative 'body      'variable-spacing-ratio 1.6)
(face-extra-add-relative 'org-quote 'variable-spacing-ratio 1.3)
(face-extra-add-relative 'org-block 'variable-spacing-ratio 0) ; suppress
(variable-spacing-mode 1)
#+end_src

In practice, ratios are declared in an =org-sty= style plist under =:faces= and applied automatically via =org-sty-remap=.

** =horizontal-layout.el= — margins, indent, text alignment

=horizontal-layout-mode= provides synthetic face properties for
horizontal text placement, implemented as face-extra pass-2 (margins)
and pass-3 (alignment) plugins.

Supported properties:

| Property                          | Effect                              |
|-----------------------------------+-------------------------------------|
| =horizontal-layout-margin-left=   | Left margin in character widths     |
| =horizontal-layout-margin-right=  | Right margin in character widths    |
| =text-align=                      | =left=, =center=, =right=, =justify= |

Properties are attached to faces via the face-extra API or declared
in an org-sty =:faces= block:

#+begin_src emacs-lisp
(face-extra-add-relative 'org-quote 'horizontal-layout-margin-left 4)
(face-extra-add-relative 'body      'text-align                   'justify)
#+end_src

Justify adds per-space =display= properties so the display engine
distributes slack across a line without changing buffer text.

** =org-title-fold.el= — fold =#+KEYWORD:= lines below =#+TITLE:=

Treats =#+TITLE:= as a pseudo-headline: TAB on that line folds/unfolds
the contiguous run of =#+KEYWORD:= lines immediately below it. Built on
=org-fold-core= (Org 9.6+). =#+TITLE:= does not need to be first.

*** Usage

#+begin_src emacs-lisp
(org-title-fold-mode 1)
#+end_src

By default, enabling the mode immediately folds the metadata block.
See =org-title-fold-fold-on-enable= to change this.

** =org-block-appear.el= — hide block delimiters, reveal near point

Hides =#+begin_=/=#+end_= block delimiter lines, revealing them only
when point is inside the block. Hiding rides on font-lock/jit-lock;
revealing is driven by =post-command-hook= with a cheap numeric range
check. Handles nested blocks correctly.

*** Usage

#+begin_src emacs-lisp
(org-block-appear-mode 1)
#+end_src

** =org-footnote-extra.el= — paragraph-local footnote placement and rendering

Adds a third footnote-definition placement strategy alongside Org's
built-in options: set =org-footnote-section= to ="*paragraph*"= to place
each definition immediately after the paragraph containing its reference.

Also renders =[fn:N]= references as raised small-caps labels with a
hanging-indent gap, using face-extra pass-1 and =body-face=.

Depends on =face-extra=, =body-face=, =horizontal-layout=.

*** Usage

#+begin_src emacs-lisp
(setq org-footnote-section "*paragraph*")
(org-footnote-extra-mode 1)
#+end_src

** =org-cite-appear.el= — render =[cite:@key]= as formatted citations

Hides raw =org-cite= markup and replaces each citation with a formatted
display string such as =(Smith, 2020)= or =(Smith & Jones, 2019, p. 14)=.
The raw markup is revealed when point enters the citation.

Citations are covered by persistent overlays (not font-lock). An idle
timer processes one pending overlay per firing, amortising citar lookup
across idle time. Soft-depends on =citar=.

*** Usage

#+begin_src emacs-lisp
(org-cite-appear-mode 1)
#+end_src

** =page-metrics.el= — physical page geometry

Translates a physical page model (page size and margins in mm/pt/in)
into the Emacs parameters =olivetti-mode= needs to render a fixed-width
page. Provides unit-conversion helpers used by other modules:

#+begin_src emacs-lisp
(page-metrics-mm-to-px mm &optional frame)
(page-metrics-pt-to-px pt &optional frame)
(page-metrics-in-to-px in &optional frame)
#+end_src

All functions accept an optional frame argument for multi-monitor use.
Soft-depends on =olivetti=.

This module is largely a stub; it's eventual use will be to define measurements for page rendering.

* Design notes

** Why =:eval= for spacing/folding/blocks?

=org-sty= intentionally knows nothing about spacing, alignment,
title-folding, or block appearance. Each concern lives in its own file
with its own minor mode. =:eval= is the composition point — the style
author wires up whatever combination makes sense for a given tag, without
=org-sty= growing new keys for every feature.

** Floor height and the =body= face model

=variable-spacing-mode= remaps =default= to a small floor height
(=variable-spacing-floor-height=, default 60 = 6pt) buffer-locally.
Prose body text opts up via the =body= face, whose visual size is set
by the =variable-spacing-ratio= synthetic property (e.g. =2.0= relative
to =default=). The global =default= face is never touched; non-sty
buffers are unaffected.

** Rendering pipeline

Face-extra dispatches four passes after Org's keyword fontification
for each jit-lock chunk:

| Pass | Work                                               |
|------+----------------------------------------------------|
| 0    | Stamp =body= on bare paragraph text (body-face)    |
| 1    | Vertical metrics: spacing ratios (variable-spacing) |
| 2    | Horizontal bounds: margins and indent (horizontal-layout) |
| 3    | Line-break-dependent: justification and alignment (horizontal-layout) |

Pass 3 is debounced: it narrows to point's visual line during typing and
defers a full paragraph re-justify to an idle timer (default 2 s).
